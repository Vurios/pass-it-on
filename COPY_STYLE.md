# Pass It On Copy Style

## Title case

Use title case for headings, button labels, category tags, and short interface labels. Capitalize every word except `a`, `an`, `the`, `and`, `or`, `but`, `for`, `nor`, `of`, `in`, `on`, `to`, `with`, `as`, `at`, and `by`. Always capitalize the first word.

Examples: `Read Aloud`, `Play Again`, `Odd Source Out`, `Host a Game`.

## Sentence case

Use sentence case for complete sentences, questions, answer options, descriptions, feedback, and error messages. Capitalize the first word and proper nouns only.

Examples: `Which source is the least credible?`, `Your room is ready. First player gets the loudest welcome.`

Keep copy direct, warm, and specific. Do not expose developer errors, transport details, or debug language to players.
